# 雑踏、僕らの街｜词卡草稿审阅

这是角色审核前的草稿。QMTS 中文作为暂定整句翻译来源；词卡、假名拆分、助词功能和片假名外来词来源待角色审核。

## 助词功能候选表

- `は`：主题提示、对比
- `が`：主语标记、强调主语
- `を`：动作对象
- `に`：时间、地点、对象或目的（按句判断）
- `で`：动作地点、手段或状态（按句判断）
- `の`：所属或修饰
- `と`：共同对象、引用或并列（按句判断）
- `も`：也、甚至；与否定搭配时表示全面否定
- `だけ`：限定范围：只、仅
- `から`：起点、原因或来源（按句判断）
- `まで`：终点、范围：直到
- `へ`：移动方向
- `ね`：征求认同、柔和语气
- `よ`：告知、强调语气
