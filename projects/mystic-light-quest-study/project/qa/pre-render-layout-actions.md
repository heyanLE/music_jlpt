# 待审核内容采纳后的版式修复

此清单不修改歌词内容，也不构成渲染授权。

当前进度：以下空间分配及共享锚点修复已实现于项目局部渲染器。42张原草稿通过检查；详情见 spacing-check.json、layout-report.json。采纳内容后仍需对修改后的卡片重跑检查。

- l008 / l029：私、の、心、癒す的罗马音互相挤压；心和癒的假名注音也发生碰撞。现有通用渲染器只按原日文宽度分配空间，没有计入注音和罗马音的宽度。
- 修复时给每个学习词块分配独立宽度，取日文、罗马音、注音所需宽度的最大值，并留出词间间隔。保持字体大小及既有纵向位置，不通过缩小罗马音隐藏问题。
- 歌词、汉字注音和罗马音必须共用字符到横坐标的映射，不能一层按整串测量、一层累加QRC碎片宽度；英语保留原顺序和时间轴，不生成额外罗马音。
- 注音仍仅位于汉字上方并左对齐；纯假名不注音，オアシス显示oasis。
- 词卡仍保持单行，卡义最多两行，词性简洁。多角色提案采纳后重新检测实际卡片数量与最长文本。
- 全部42帧重做重叠检测，并目视检查l008、l018、l027、l029和纯英文l012；再检查合成到实际背景上的透明度及高亮。当前透明前景PNG不可视为最终合成验收。

不得在修复过程中改动QMTS整句中文、QRC原文或时码。修复后的渲染器及内容应绑定新的渲染授权哈希。
