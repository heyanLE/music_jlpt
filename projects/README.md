# 日语歌曲跟读视频项目归档

每个项目保留三类副本：

- `source/`：用户提供的音频、视频、QRC 和封面来源。
- `project/`：审核数据、封面、抽取音频和该项目渲染脚本。
- `deliverables/`：最终视频、16:9/4:3 封面、审核文档及已解码 QRC 数据。
