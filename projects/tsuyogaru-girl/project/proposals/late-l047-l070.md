# l047–l070 assisted review proposal

Scope: tokenization, kanji-only furigana, romaji, part of speech, particle functions, and loanword source annotations. This is a proposal only; it does not modify `frames.json`.

## Translation rule

Every `caption.translationZh` must be copied from QMTS unchanged. Do not rewrite it. l051 has no QMTS translation in the current source, so retain its existing pending placeholder.

## Shared rules

- For particles, use `functionZh`, not `zhMeaning`.
- For katakana loanwords, add `sourceWord` and render it in the annotation position: `ミラクル` → `miracle`; `ヒロイン` → `heroine`; `ガール` → `girl`; `トゥルーエンディング` → `true ending`.
- Furigana applies only to kanji runs. Repeated kanji runs need `occurrence`.
- l048 `駆けずって` is confirmed as the published lyric spelling; retain its QRC surface and treat it as one stylized verb token.
- l068/l069 retain all QRC timing parts/highlights, but only create semantic cards for `負け`; repeated standalone `け` morae do not get a card.
