# 中段联网审核提案：l024–l046

状态：`proposed-not-merged`  
范围：仅审核分词、词性／助词功能、汉字振假名、罗马音与片假舶来语注释。  
**整句中文规则：`caption.translationZh` 一律直接使用 QMTS，不得自行改写。** 因此 l024 保留 QMTS 的“（待结合上下文核对中文）”占位。

## 导入约定

- `furigana` 仅标注汉字 run；纯平假名不标注。
- `sourceWord` 用于片假名词上方的原始外来语标注，替代平假名振假名。
- 下列数组依次为：`token / reading / romaji / meaning-or-function / posZh`。
- 助词卡仅填写功能，不填写普通词义。
