# 基于 QMTS 整句中文的二次词卡审阅（提案）

审阅范围：l001–l070。中文整句只作语义锚点；词性与助词功能仍以日文原句为准。以下是需要改动的高/中置信提案，未列出的词卡与当前整句中文一致，可保留。

已保护的人工修正：l001、l068、l069 的「負け＝失败｜名词」不改动；虽然 QMTS 将它意译为“败犬”，不以意译反向覆盖词典义。

| 帧 | 整句中文锚点 | 建议 | 置信度 |
| --- | --- | --- | --- |
| l007 | 生来就有做公主的潜质 | 「天然由来」从“天然来源的”调整为“天生自带的、与生俱来的”，更符合歌词语境。 | 高 |
| l008 | 今天也在到处上演着失败群像剧 | 「敗北群像劇」从“失败者群像剧”调整为“失败群像剧；失败者们的群像剧”，避免无依据补出“者”。 | 高 |
| l009 | 心中忐忑不安，感到隐隐作痛 | 合并为「ドキドキして」「ズキズキする」。原先把「して／する」拆成独立词卡，会失去拟声词的状态表达。 | 高 |
| l016 | 莫名地想要奔跑起来 | 合并「謎に」，释义改为“莫名地、不可思议地”；不把「謎」单独按实体“谜”解释。 | 高 |
| l019 | 保持和平的心态 | 「ピースして」改为“保持和平／保持平和状态”。该处 QMTS 采用 peace 义；保留“剪刀手”会与整句明显冲突。 | 中 |
| l020 | 一次又一次地历经失败吧 | 合并「負けてやれ」，释义“尽管失败吧／索性输个痛快吧”，而非将「やれ」孤立解释为普通命令。 | 高 |
| l021 | 每次落泪都会使我变强 | 合并「強くなる」，释义“变得坚强”，避免「強く」被误解成单纯“强烈地”。 | 高 |
| l038 | 不停发起攻势，命中率只有 3% | 将「命中」释义明确为“命中率”；补一张「3%＝3%｜数量表达」卡，使中文中的关键数值有对应。 | 高 |
| l043 | 作战失败，一切仍未完待续 | 「コンティニュー」释义改为“续关、继续挑战”；更贴合游戏语境的“失败后 continue”。 | 高 |

| l059 | 成为那个女主角，我在心中如此起誓 | 合并「ヒロインになる」，释义“成为女主角”；保留「と」为引用誓言内容。 | 高 |

## 可保留但应理解为中文意译的行

- l005「間違いない」仍建议保持“确实无误、毋庸置疑”，不直接改成 QMTS 的“无可厚非”。
- l024「走れ」仍为“奔跑吧”；QMTS 的“运转吧”是对“命运”的意象转译。
- l039「イタチごっこ」仍为“无休止的反复对抗”，不按 QMTS 的“捉迷藏”直译。
- l056「泣いてきた」仍为“一直哭到现在”，不因 QMTS 的诗化表达改动词性。
